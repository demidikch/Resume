# Когортный анализ на SQL

Расчёт ключевых метрик удержания и монетизации по когортам покупателей интернет-магазина. Практика модуля «Продвинутый SQL» (Яндекс Практикум).

**СУБД:** PostgreSQL  
**Схема базы:** [schema.png](schema.png)

## Данные

База интернет-магазина `tools_shop`: пользователи, события в приложении, заказы, товары и расходы на привлечение.

## Метрики

| Файл | Метрика | Когорта | Как считается |
|------|---------|---------|---------------|
| [01_retention_rate.sql](01_retention_rate.sql) | **Retention Rate** | месяц первого события покупателя | доля пользователей когорты, активных в каждом следующем месяце |
| [02_ltv.sql](02_ltv.sql) | **LTV** | месяц регистрации (2019 год) | выручка когорты с накоплением по лайфтайму, делённая на размер когорты |
| [03_churn_rate.sql](03_churn_rate.sql) | **Churn Rate** | месяц первого события покупателя | доля пользователей, активных в прошлом месяце, но не вернувшихся в текущем |

## Приёмы

Цепочки CTE, JOIN, `DATE_TRUNC`, `AGE`, оконные функции (`COUNT OVER`, `SUM OVER` с накоплением, `LAG`), приведение типов и расчёт долей в процентах.
