# Анализ данных StackOverflow на SQL

Самостоятельный проект модуля «Продвинутый SQL» (Яндекс Практикум).

**СУБД:** PostgreSQL  
**Схема базы:** [schema.png](schema.png)

## Данные

Выгрузка сервиса вопросов и ответов StackOverflow за 2008 год: пользователи, посты (вопросы и ответы), голоса за посты и их типы, значки пользователей.

## Задачи

**[Часть 1](part1.sql): 13 задач**
- количество популярных вопросов, средняя активность по дням;
- пользователи, получившие значки в день регистрации;
- рейтинги пользователей по голосам и значкам (`ROW_NUMBER`, `DENSE_RANK`);
- средние очки постов автора (`AVG OVER`);
- сегментация пользователей по числу просмотров профиля и лидеры сегментов (`CASE`, CTE);
- ежедневный прирост пользователей с накоплением (`SUM OVER`);
- время от регистрации до первого поста (`FIRST_VALUE`).

**[Часть 2](part2.sql): 7 задач**
- просмотры постов по месяцам;
- самые активные новички: больше 100 ответов в первый месяц;
- активность когорты пользователей сентября 2008 года;
- накопительная сумма просмотров по каждому автору;
- среднее число активных дней за первую неделю декабря;
- изменение количества постов месяц к месяцу в процентах (`LAG`);
- активность самого продуктивного автора по неделям.

## Приёмы

JOIN, подзапросы, CTE, `CASE`, агрегации с `HAVING`, работа с датами (`DATE_TRUNC`, `EXTRACT`, интервалы), оконные функции: `ROW_NUMBER`, `DENSE_RANK`, `FIRST_VALUE`, `LAG`, `SUM/AVG/COUNT OVER` с накоплением и партициями.
