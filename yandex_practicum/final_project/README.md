## Задача

Приложение «Ненужные вещи» — доска объявлений, где пользователи продают свои вещи. Целевое действие — просмотр контактов продавца. Нужно:

- найти сценарии, которые чаще всего приводят к просмотру контактов, и построить по ним воронки;
- сравнить время до целевого действия в разных сценариях;
- выяснить, чем отличается поведение пользователей, которые смотрят контакты, от остальных;
- проверить статистические гипотезы о конверсии.

## Данные

74 197 событий пользователей, которые впервые открыли приложение после 7 октября 2019 года: время события, id пользователя, тип действия (просмотр объявления, фотографий, рекомендаций, поиск, карта, добавление в избранное, звонок и т. д.), источник установки.

## Что сделано

- Предобработка: проверка пропусков и дубликатов, приведение типов, разбивка событий на сессии (тайм-аут сессии — 20 минут, длина сценария — медианные 3 шага).
- Выделение основных сценариев и построение воронок по уникальным пользователям.
- Расчёт времени между событиями внутри сессий.
- Сравнение частоты действий у пользователей с целевым событием и без него.
- Проверка гипотез о равенстве долей (z-тест).
- Дашборд в Tableau: распределение событий по типам, число пользователей, фильтр по дате.

## Результаты

**Конверсия в просмотр контактов по основным сценариям:**

| Сценарий | Конверсия |
|----------|-----------|
| map → tips_show → contacts_show | 19% |
| tips_show → contacts_show | 18% |
| search → photos_show → contacts_show | 12% |
| tips_show → map → contacts_show | 10% |

- От поиска до просмотра контактов пользователи доходят быстрее, чем от карты: 6 мин 18 с против 8 мин 39 с.
- **Гипотеза 1:** конверсия у пользователей, которые кликают по рекомендациям, отличается от тех, кто их только видит. **Подтверждена**: 30,6% против 17%, разница статистически значима.
- **Гипотеза 2:** конверсия отличается у сессий до и после 14:00. **Не подтверждена**: 20,8% против 21,4%, p-value = 0,56.

## Рекомендации

- Объединить дублирующиеся события `show_contacts` и `contacts_show`.
- Развивать рекомендации: клик по рекомендованному объявлению значимо повышает конверсию.
- Пересмотреть карточку объявления (`advert_open`): это одно из самых редких действий.
- Рекламу можно запускать в любое время суток: конверсия днём и вечером не различается.
