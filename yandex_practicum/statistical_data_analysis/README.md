# Анализ тарифов оператора связи

**Ноутбук:** [statistical_data_analysis.ipynb](statistical_data_analysis.ipynb) · [HTML-версия](statistical_data_analysis.html)

## Задача

Оператор связи предлагает два тарифа: «Смарт» и «Ультра». Нужно сравнить поведение клиентов на этих тарифах и проверить, различается ли выручка между тарифами и между регионами.

## Данные

Звонки, сообщения и интернет-сессии клиентов оператора, данные о клиентах (город, тариф) и условия тарифов.

## Что сделано

- Предобработка: приведение типов, расчёт помесячного потребления (минуты, сообщения, трафик) по каждому клиенту.
- Расчёт помесячной выручки с учётом абонентской платы и превышения лимитов.
- Сравнение распределений потребления на двух тарифах, анализ динамики по месяцам.
- Проверка статистических гипотез (t-тест Уэлча, α = 0,05).

## Результаты

- Клиенты «Ультра» в среднем отправляют примерно на 20 сообщений в месяц больше, чем клиенты «Смарт».
- Типичный расход интернета: 15–17 ГБ в месяц на «Смарте» и 19–21 ГБ на «Ультре». Меньше всего связь используют в январе, феврале и апреле.
- **Гипотеза 1:** средняя выручка на тарифах различается. **Подтверждена** (p < 0,001).
- **Гипотеза 2:** выручка от клиентов из Москвы отличается от выручки в других городах. **Не подтверждена** (p = 0,53).

## Инструменты

Python (pandas, NumPy, SciPy, Matplotlib, Seaborn), проверка статистических гипотез, t-тест
