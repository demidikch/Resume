# Исследование рынка недвижимости Санкт-Петербурга

**Ноутбук:** [exploratory_data_analysis.ipynb](exploratory_data_analysis.ipynb) · [HTML-версия](exploratory_data_analysis.html)

## Задача

По архиву объявлений сервиса Яндекс.Недвижимость о продаже квартир в Санкт-Петербурге и соседних населённых пунктах определить параметры, которые влияют на рыночную стоимость. Результаты нужны для автоматической системы, которая будет отслеживать аномалии и мошеннические объявления.

## Данные

Объявления за несколько лет: данные, которые ввёл пользователь (площадь, этаж, число комнат, высота потолков и т. д.), и данные, рассчитанные автоматически по картографии (расстояние до центра, аэропорта, парков и водоёмов).

## Что сделано

- **Предобработка:** заполнение пропусков с обоснованием выбранного способа, приведение типов, устранение неявных дубликатов в названиях населённых пунктов, удаление редких и аномальных значений.
- **Новые признаки:** цена квадратного метра, день недели, месяц и год публикации, тип этажа (первый, последний, другой), расстояние до центра в километрах.
- **Исследовательский анализ:** сроки продажи, зависимость цены от параметров квартиры, сравнение стоимости квадратного метра по населённым пунктам, зависимость цены от расстояния до центра.

## Результаты

- Квартиры продаются в среднем за 95 дней (медиана): быстрые продажи занимают около 45 дней, долгие — около 193.
- Цена прямо зависит от общей и жилой площади, площади кухни и числа комнат.
- Квартиры на первом и последнем этажах заметно дешевле остальных.
- Чем ближе к центру Санкт-Петербурга, тем выше цена.
- Для автоматической системы рекомендуется рассчитывать цену квадратного метра и расстояние до центра автоматически, а для частых пропусков задавать значения по умолчанию.

## Инструменты

Python (pandas, Matplotlib), предобработка данных, исследовательский анализ, сводные таблицы
