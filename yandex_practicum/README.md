# Проекты курса «Аналитик данных» (Яндекс Практикум)
Обучение подтверждено справкой об окончании программы (350 ак. ч.): [certificate.pdf](certificate.pdf)
| Проект | Задача | Инструменты и методы |
|--------|--------|----------------------|
| [final_project](final_project) — поведение пользователей мобильного приложения | Сценарии, которые приводят к целевому действию, воронки, рекомендации по продукту | Python, Plotly, z-тест, Tableau |
| [ab_testing](ab_testing) — A/B-тест для интернет-магазина | Приоритизация гипотез, анализ A/B-теста, решение по тесту | Python, SciPy, ICE/RICE, критерий Манна-Уитни |
| [marketing_roi](marketing_roi) — окупаемость рекламы | Причины низкой окупаемости рекламы, рекомендации маркетингу | Python, LTV, CAC, ROI, retention, когорты |
| [statistical_data_analysis](statistical_data_analysis) — тарифы оператора связи | Сравнение поведения и выручки клиентов двух тарифов | Python, Seaborn, t-тест |
| [exploratory_data_analysis](exploratory_data_analysis) — рынок недвижимости | Факторы, которые влияют на стоимость квартиры | Python, pandas, исследовательский анализ |

В каждой папке — исследование (ноутбук `.ipynb` и/или HTML-версия) и README с описанием задачи, хода работы и выводов.
